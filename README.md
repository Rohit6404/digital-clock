# ⏰ Digital Clock

A clean, modern, and responsive **Digital Clock** built using HTML, CSS, and JavaScript. It displays the current time in 12-hour format with AM/PM and the current date, updating automatically every second.

## ✨ Features

- 🕒 **Real-Time Clock** — Displays the current time and updates every second.
- 🌗 **12-Hour Format** — Shows hours, minutes, seconds, and AM/PM.
- 📅 **Live Date Display** — Shows the weekday, day, month, and year.
- 📱 **Responsive Design** — Adapts to different screen sizes.
- 🎨 **Modern UI** — Clean dark theme with a stylish clock display.
- ⚡ **Lightweight & Fast** — Built with vanilla JavaScript without external libraries.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Structures the webpage |
| CSS3 | Styling, layout, and responsiveness |
| JavaScript | Time logic, date formatting, and live updates |

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Rohit6404/digital-clock
```

### 2. Open the Project

```bash
cd digital-clock
```

Open the folder in VS Code.

### 3. Run the Application

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

That's it! Your Digital Clock is ready to use.
